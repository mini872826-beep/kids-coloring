# 🎒 大班學英文

幼稚園大班英文課本的有聲複習 App（另一個 PWA，和「小朋友愛畫畫」分開安裝）。

網址：https://mini872826-beep.github.io/kids-coloring/school/
（iPad 用 Safari 打開 → 分享 → 加入主畫面）

## 每一課（10 課＋總複習）
| 功能 | 內容 |
|---|---|
| 👆 點點看 | 課本那一頁：點圖片聽英文、中文和句型（I see the crosswalk.）；念謠可以一句一句點，或「全部念一遍」 |
| 📘 跟老師複習 | 自動一步一步念：問句 → 每個單字和句型 → 念謠（英文＋中文意思） |
| 🚗🐻🧱🐸 小遊戲 | 賽車、餵小熊、蓋高塔、青蛙跳荷葉：聽英文選圖，答對就前進 |
| ✏️ 小小考試 | 10 題聽力：聽單字選圖、聽句子選圖、農場 Do you see…? 選 Yes / No；答錯的最後「訂正時間」一題一題講 |

第 3 課「我的老師」可以在點點看裡寫上老師的名字。

## 檔案
| 檔案 | 內容 |
|---|---|
| `js/lessons.js` | 課本內容：每課的問句、句型、單字、念謠（要改課本內容改這裡） |
| `js/school.js` | 出題、複習、點點看 |
| `js/game.js` | 小遊戲、小考、訂正（從小朋友愛畫畫的學數學搬來） |
| `js/voice.js` | 念字和音效 |

## 聲音
錄音和小朋友愛畫畫共用（`../audio/`）：中文是老師（MiniMax 台灣腔大姊姊）的聲音，英文是英文的聲音。
`tools/phrases.js` 會把 `js/lessons.js` 的句子收進錄音清單，推上 GitHub 後自動錄好。
每次更新記得改 `js/version.js`。
