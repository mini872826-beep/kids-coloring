# 🎒 小書包學習本

小朋友的有聲複習本（另一個 PWA，和「小朋友愛畫畫」分開安裝）。照學校的課本，分科目、分學期放在書架上，小朋友長大就一直加新的書。

網址：https://mini872826-beep.github.io/kids-coloring/school/
（iPad 用 Safari 打開 → 分享 → 加入主畫面）

## 怎麼分類
**書架（照學期分區）→ 一本書（標上科目）→ 一課一課**

| 學期 | 書 |
|---|---|
| 大班上學期 | 🔤 英文課本（10 課） |

- 科目：英文、注音、數學（`js/shelf.js` 的 `SUBJECTS`，要加新的科目加一行）
- **誰要學習**：首頁可以新增小朋友（哥哥、妹妹……），每個人的星星、老師的名字分開存。再點一次已選的名字可以改名
- **📒 貼紙本**：做完小小考試、玩完小遊戲、「跟我說」或「口說練習」說完一課，都會得到一張貼紙（每個小朋友分開收集）
- **手機、平板都可以用**：直的、橫的都會自動排好
- **英文速度**：右上角 🐇 1 倍 → 🐢 0.75 倍 → 🐌 0.5 倍。只放慢英文，老師的中文維持正常。慢速的英文是另外錄好的（AI 真的慢慢念），還沒錄好的先把正常錄音放慢播

## 英文課本的每一課（10 課＋總複習）
選單照學習的順序分成五段：**① 上課 → ② 課本 → ③ 口語練習 → ④ 練習小遊戲 → ⑤ 小小考試**

| 功能 | 內容 |
|---|---|
| 📘 老師上課 | 自動一步一步念：問句 → 每個單字和句型 → 念謠（英文＋中文意思）；可以上一頁、下一頁、再聽這一頁，上完課按「下一步：課本」 |
| 👆 點點看 | 課本那一頁：點圖片聽英文、中文和句型；念謠可以一句一句點，或「全部念一遍」 |
| 🗣️ 跟我說 | 老師念一句英文 →「換你說！」停下來讓小朋友跟著說（停的時間照句子長短，慢速時停久一點）→ 下一句；單字 → 句型 → 念謠。不用麥克風 |
| 🎤 口說練習 | 按「開始」允許麥克風 → 老師說一句、小朋友說一句：錄下來馬上放給他聽，同時用手機內建的語音辨識和老師的句子一個字一個字比（說到的字綠色、沒說到的紅色）→ 整課說完進「訂正時間」：聽老師、聽自己剛剛說的、再說一次（最多 8 句、只跑一輪）。說不好的句子會記起來，下次可以「練習上次說不好的」。錄音不會存起來，也不會上傳 |
| 🚗🐻🧱🐸 小遊戲 | 賽車、餵小熊、蓋高塔、青蛙跳荷葉：聽英文選圖，答對就前進 |
| ✏️ 小小考試 | 10 題聽力：聽單字選圖、聽句子選圖、農場 Do you see…? 選 Yes / No；最後「訂正時間」 |

## 加一本新的書
1. 在 `js/books/` 新增一個檔案（照 `english-k2-1.js` 的樣子），`window.SHELF.addBook({ id, subject, grade, term, title, icon, color, dark, type, tiers, units })`
   - `id` 不能和別本重複（星星用它存）；`grade`＋`term` 決定放在書架哪一區（例如「大班」「下學期」）
   - `type` 是這本書用哪一種題目：目前有 `english`（聽英文選圖、點點看、念謠，在 `js/school.js`）。注音、數學要做新的 type
2. 在 `index.html` 和 `sw.js` 加上這個檔案
3. 改 `js/version.js`，推上 GitHub，配音會自動錄好

## 檔案
| 檔案 | 內容 |
|---|---|
| `js/shelf.js` | 書架：科目、登記書、念的固定用語、畫好的小圖 |
| `js/books/` | 一本書一個檔案 |
| `js/school.js` | 英文課本這種書：出題、複習、點點看 |
| `js/game.js` | 小遊戲、小考、訂正（從小朋友愛畫畫的學數學搬來） |
| `js/voice.js` | 念字（含英文速度）和音效 |
| `js/app.js` | 首頁書架、誰在學習、換畫面、更新 |

## 聲音
錄音和小朋友愛畫畫共用（`../audio/`）：中文是老師（MiniMax 台灣腔大姊姊）的聲音，英文是英文的聲音（另外錄 0.75 倍、0.5 倍的慢速版）。
`tools/phrases.js` 會把書架裡所有的句子收進錄音清單，推上 GitHub 後自動錄好。
