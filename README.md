# 🎨 小朋友愛畫畫

給小朋友玩的塗色繪本 PWA（純 HTML/CSS/JS，沒有建置步驟，可離線使用）。

網址：https://mini872826-beep.github.io/kids-coloring/

## 功能
- **塗顏色**：車車 / 動物 / 恐龍 / 海洋 / 萬聖節，共 40 張線稿；線條外粗內細
- **自由畫**：可以一直「新增白紙」，每張分開保存，不要的可以按 ✕ 丟掉
- **9 種筆**：油漆桶、馬克筆、蠟筆、鉛筆、水彩筆、噴漆、閃粉筆、彩虹筆、花紋筆，3 種粗細
- **56 色色板**（8×7）+ 自選顏色
- **點什麼念什麼**：分類、圖卡、筆、顏色都會用中文念出來，幫小朋友認字
- 橡皮擦、上一步、全部擦掉（會再問一次）、📷 存到相簿
- 每張畫**自動保存**在平板本機，首頁縮圖直接顯示作品
- **聽故事**：3 本小故事，點進去自動朗讀、自動翻頁

## 自動更新
有網路時 App 會先抓最新版，沒網路才用離線快取。
所以改完推到 GitHub `main`，等 1～2 分鐘，平板下次打開就是新版。

## 本地預覽
```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 加新線稿
在 `js/art.js` 的 `DRAWINGS` 裡加一項：800×600 的 SVG 內容，形狀要封閉（油漆桶才填得滿）。
`fill="#222"` 是固定黑色（眼睛等），其他顏色只在故事裡顯示，塗色時會自動變成空白。
