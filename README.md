## 聲音
- **點什麼念什麼**：分類、圖卡、筆、顏色、花紋都會念出來，幫小朋友認字
- **AI 配音**：`tools/gen_voice.py` 用台灣口音的「曉雨」把每一句錄成 mp3（`audio/`）。
  GitHub Actions（`.github/workflows/voice.yml`）每次推上新內容會自動補錄，錄不到的才用 iPad 內建語音
- **背景音樂**：程式現場合成的八音盒小曲，念字時自動變小聲，首頁 🎵 可開關

## 更新
- 有網路時先抓最新版，沒網路才用離線快取
- App 開著時會自己定期檢查新版，在首頁時自動換新版並跳出提示；畫畫、聽故事時不打斷
- 每次更新記得改 `js/version.js` 的版本號（首頁右下角會顯示）

## 加新線稿／故事
- 線稿：在 `js/art.js` 的 `DRAWINGS` 加一項（800×600 SVG，形狀要封閉）。`fill="#222"` 是固定黑色，其他顏色只在故事裡顯示
- 故事：在 `js/books.js` 加一本，`tag` 填 品德／習慣／經典／冒險／節日
- 推上 GitHub 後，配音會自動補錄
