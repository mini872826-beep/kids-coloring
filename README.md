# 🎨 小小绘本屋

给小朋友玩的涂色绘本 PWA（纯 HTML/CSS/JS，没有构建步骤，可离线使用）。

## 功能
- **涂颜色**：车车 / 动物 / 恐龙 / 海洋 / 自由画（白纸），共 17 张线稿
- **9 种笔**：油漆桶（点一下填满一块）、马克笔、蜡笔、铅笔、水彩笔、喷漆、闪粉笔、彩虹笔、花纹笔，3 种粗细
- **56 色色板**（8×7）+ 自选颜色
- 橡皮擦、上一步、全部擦掉（会再问一次）、📷 存到相册
- 每张画**自动保存**在平板本机（IndexedDB），首页缩图直接显示作品
- **听故事**：2 本小故事，系统语音朗读、自动翻页、点画面里的东西会动会响
- 横屏工具栏在右边，竖屏自动移到下面

## 本地预览
```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 装到 iPad
PWA 需要 HTTPS 网址。部署到任意静态网站托管（例如 GitHub Pages / Netlify / Cloudflare Pages）后：
Safari 打开网址 → 分享 → **添加到主屏幕**。之后就像 App 一样全屏打开，断网也能用。

## 加新线稿
在 `js/art.js` 的 `DRAWINGS` 里加一项：800×600 的 SVG 内容，形状要封闭（油漆桶才填得满）。
`fill="#222"` 是固定黑色（眼睛等），其他颜色只在故事里显示，涂色时会自动变成空白。

## 更新后
修改文件后把 `sw.js` 里的 `VERSION` 加一，平板下次打开就会拿到新版本。
